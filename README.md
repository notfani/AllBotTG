# @all бот для Telegram

Тегает участников чата, когда админ или владелец пишет `@all`.
Список ведётся отдельно для каждого чата.

## Кого запоминает

- кто написал сообщение после добавления бота;
- кто зашёл: служебное сообщение `new_chat_members` и обновление `chat_member`.

Вышедших и кикнутых удаляет. Уже сидевших в группе на момент добавления бота Telegram не отдаёт: у Bot API нет списка участников.

Чтобы видеть входы без служебного сообщения, бот должен быть администратором.

## Запуск через Docker

1. В [@BotFather](https://t.me/BotFather) создайте бота и скопируйте токен.
2. Там же: `/setprivacy` → выберите бота → **Disable**.
3. Подготовьте окружение и запустите:

```bash
cp .env.example .env
# впишите BOT_TOKEN в .env
docker compose up -d --build
docker compose logs -f
```

База лежит в `./data/users.db` и переживает перезапуск контейнера.

Остановить: `docker compose down`. Пересобрать после правок: `docker compose up -d --build`.

## Без Docker

```bash
pip install -r requirements.txt
cp .env.example .env
python bot.py
```

## В группе

Добавьте бота и сделайте администратором. Права нужны и для проверки админа, и для событий входа.

- `@all` или `/all` — только владелец и администраторы.
- Обычный участник получит отказ.
- `/count` — сколько человек в базе этого чата.
- Упоминания уходят пачками по 25.
